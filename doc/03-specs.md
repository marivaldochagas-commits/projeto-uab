# 03 - Especificações de Frontend (Sistema de Atendimento)

## Melhorias Implementadas - Aula 10
- **Comportamento Visual:** Padronização de cores e fontes para o sistema de Help Desk.
- **Responsividade:** Layout adaptável para dispositivos móveis e desktops usando Bootstrap.
- **Acessibilidade:** Inclusão de labels em todos os formulários e navegação facilitada por teclado.
- **Mensagens de Erro:** Implementação de feedbacks visuais em vermelho para campos inválidos no login.
- **Estados de Carregamento:** Feedback visual enquanto o servidor processa a abertura de tickets.
